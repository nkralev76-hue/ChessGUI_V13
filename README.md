# ChessGUI V13

Chess GUI with dual UCI engine support, PGN replay, tournament mode, and Ponder (permanent brain).

**Author:** Nikolay Kralev
**License:** MIT (see [LICENSE](LICENSE))

## Features

- Dual UCI engine analysis with per-engine panels
- PGN load, replay (arrow keys), and export
- Tournament mode (engine vs engine)
- Ponder / Permanent Brain
- Opening book support
- Built-in engine included
- Windows icon (rook)

## Installation

1. Download `ChessGUI_V13_sfx.exe`
2. Run it — a dialog will ask where to install
3. Choose a destination folder (a `ChessGUI_V13/` folder will be created there)
4. Run `chess_gui_v13.exe`

## Files

| File | Description |
|------|-------------|
| `chess_gui_v13.exe` | Main application |
| `ChessGUI_V13_sfx.exe` | Self-extracting installer |
| `SDL2.dll` | SDL2 library |
| `SDL2_image.dll` | SDL2 image library |
| `SDL2_ttf.dll` | SDL2 TTF library |
| `pieces/` | Chess piece images |
| `fonts/` | DejaVuSans font |

## Requirements

- Windows 7 or later
- No additional software needed (all DLLs included)
